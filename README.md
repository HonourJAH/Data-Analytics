## select-statement.sql
- Learnt SELECT statements. It's used to select column(s) from a table or add columns to the result table.
- scenerios like when using aggregate functions and case statements


## union.sql
- UNION is used to join the results of two SELECT statements


## where-statement.sql
- WHERE is used for filtering the rows based on the defined condition


## groupby_orderby.sql
- GROUP BY collapses the rows that are similar together into a single on which aggregate functions can be used
- ORDER BY is used to order either in ascending(default) or in descending order
- It is used on both numerical(INT) and strings(text) columns.


## having-vs-where.sql
- HAVING is used on grouped rows to filter the rows based on defined condition


## joins-statement.sql
- my friend JOINS is used to join several tables together
- There are a few joins: INNER JOIN, LEFT JOIN, RIGHT JOIN, CROSS JOIN(effect of SELF JOIN, i.e, joining the same table to itself)


## limiting_aliasing.sql
- LIMITING (using the LIMIT) statement is used to control the number of rows to be shown in a result table
- ALIASING (using the AS clause) is a way of renaming either the query parameters such as table names especially when using self joins in order for better identification. It can be used to rename a column too
